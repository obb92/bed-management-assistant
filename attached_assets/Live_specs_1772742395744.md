## WHAT THIS APP IS

CareFlow is a React demo prototype of an AI-powered bed management assistant for hospital Bed Coordinators and Charge Nurses. It is built for a case interview presentation at Qualified Health. It must look polished and work reliably in a live demo setting.

**This is not a production app.** All patient data is synthetic. There is no real EHR integration. The only live AI component is the chat interface.

## TECH STACK (DO NOT CHANGE)

- **Framework:** React + Vite
- **Styling:** Tailwind CSS only. No custom CSS files unless absolutely necessary.
- **AI:** Anthropic Claude API. Model: `claude-sonnet-4-20250514`. Endpoint: `https://api.anthropic.com/v1/messages`. API key via `import.meta.env.VITE_ANTHROPIC_API_KEY`.
- **State:** React useState/useReducer only. No external state library. No localStorage.
- **Routing:** No React Router. Single page, nav managed via React state (`activePage`).
- **No backend.** No database. No auth.

```javascript
    tc1_coord_card2: "default" | "done" | "updated",  // updated = nurse confirmed

    // TC2 coordinator

    tc2_coord_card3: "default" | "done",
    // TC2 nurse

  },

```

**State reset rules:**
- Switching scenario resets all `actionCardStates`, `flagText`, `chatHistory`
- Switching persona does NOT reset state
- Switching scenario does NOT reset `activePersona`

## FEEDBACK LOOP LOGIC

This is the most important interaction in the app. Implement exactly as described:

**TC1 feedback loop:**
- When `tc1_nurse_card1` → "confirmed": set `tc1_coord_card2` → "updated"
- Coordinator Card 2 text changes to: *"3 South confirmed: transport arranged for Room 310. Discharge initiated. Room ETA 35 min. Mr. Torres assignment on track."*
- Bed board: Room 310 tile transitions blue → green → red

**TC2 feedback loop:**
- When `tc2_nurse_card1` → "flagged" (with flagText submitted): set `tc2_coord_card1` → "updated"
- Coordinator Card 1 text changes to: *"Room 412 discharge delayed — family requesting physician consult. 10:30am admit assignment at risk. Recommend reassigning to Room 418, 3 North (confirmed clear by 9:45am)."*

Both updates happen via React state only — no API call required.

```
You have full visibility into the current hospital state.
Answer questions about bed management, discharge planning, and patient flow only.
Be specific — always reference actual room numbers, patient names, and timing from the hospital state below.
Never give generic answers. Keep responses to 3–5 sentences max unless a list is genuinely clearer.
Do not speculate beyond the data provided. Do not give clinical advice.

CURRENT HOSPITAL STATE:
[PASTE FULL SCENARIO JSON HERE — see Data Layer section]
```

## DEMO CALL-OUT SCRIPTS (AUDIENCE-FACING)

**Critical rule:** Call-out cards are visible to the audience on a shared screen. All text must be narrative and audience-facing. No presenter meta-instructions (e.g. "read this aloud", "point to the stats bar"). Each step has: a title, a body (what's happening in the scenario), and a pointer arrow anchored to the next element to interact with.

---

### TC1 — "The 2am Crunch" (6 steps)

**Step 1 of 6 — AI Situation Briefing**
Body: "It's 2:15am. The house is at 94% occupancy with 6 ED boarders — 3 waiting over 4 hours. The Bed Coordinator opens CareFlow and gets an instant plain-English briefing. No dashboard. No analyst needed."
Pointer: arrow anchored to the AI Situation Briefing card

**Step 2 of 6 — Priority Action Queue**
Body: "The AI has surfaced exactly 3 priority actions — ranked by urgency and impact. Deliberately capped at 3. This is a design choice: no alert fatigue. Each card tells you what to do, who owns it, and why."
Pointer: arrow anchored to Action Card 1

**Step 3 of 6 — AI Reasoning**
Body: "Card 2 recommends initiating Mrs. Garcia's discharge on 3 South. The AI synthesized 4 data signals to reach this — labs back, family present, physician sign-off received, transport not yet arranged. Click the card to see the reasoning."
Pointer: arrow anchored to Card 2 body (not buttons)

**Step 4 of 6 — The Charge Nurse View**
Body: "The same AI — completely different view. The Charge Nurse on 3 South only sees her floor, with one specific task waiting for her. Switch to her perspective using the persona switcher."
Pointer: arrow anchored to persona switcher (top right)

**Step 5 of 6 — Last-Mile Execution**
Body: "The Charge Nurse has one task: arrange transport for Mrs. Garcia and confirm discharge. This is the execution the Coordinator can't do from the hospital-wide view. She confirms it here."
Pointer: arrow anchored to Confirm button on Nurse Card 1

**Step 6 of 6 — The Feedback Loop**
Body: "Card 2 has updated automatically. The Coordinator now knows transport is arranged and Mr. Torres's assignment is on track — no phone call, no manual check. The AI closed the loop between Coordinator and Nurse."
Pointer: arrow anchored to updated Card 2
